시행일: 2026년 10월 19일 · 대상: 윙도쿠 iOS·Android 앱 및 고객지원 페이지

goyo works (고요웍스 | 개인사업자, 이하 운영자)는 게임 제공, 기록 복원, 광고 보상 확인과 고객지원을 위해 아래 정보를 처리합니다.

1. 처리하는 정보와 목적

  • 게스트 및 게임 정보: 임의로 발급한 사용자 식별자, 닉네임, 선택한 프로필, 레벨 진행, 표시한 칸, 완료 기록, 보유 아이템, 보상·순위 및 설정을 저장합니다. 게임 이어 하기, 기록 동기화, 순위 계산과 중복 보상 방지에 사용합니다.
  • 선택한 계정 연결: Apple 또는 Google에서 제공한 계정 식별자와 이메일 주소를 로그인 및 기록 복원에 사용합니다. Apple의 이메일 가리기를 쓰면 전달용 주소가 제공될 수 있습니다. 운영자는 Apple·Google 계정 비밀번호를 받지 않습니다.
  • 광고: Google AdMob 광고 도구가 IP 주소, 기기·광고 식별자, 광고 노출·상호작용, 앱 사용·성능 및 오류 정보를 처리할 수 있습니다. 광고 제공, 측정, 부정 사용 방지 및 보상 확인에 사용됩니다. 운영자의 보상 서버에는 광고 거래 식별자, 게임 사용자 식별자, 보상 종류와 지급 시각을 저장합니다.
  • 문의: 사용자가 보낸 이메일 주소, 문의 내용과 직접 첨부한 사진·기기 정보 등을 문제 확인과 답변에 사용합니다.
  • 서비스 접속: 서버 및 웹 호스팅 제공자는 IP 주소, 요청 시각과 기술적 접속 기록을 서비스 운영과 보안 목적으로 처리할 수 있습니다.

2. 기기 저장과 서버 전송

플레이 중 동작은 우선 기기에 저장합니다. 다음 판 이동, 앱이 배경으로 이동하는 시점, 계정 작업 등 저장이 필요한 시점에 서버와 동기화합니다. 로그인 정보는 기기의 보안 저장소에 보관합니다. 기록을 파일로 내보내면 파일의 보관·공유는 사용자가 관리합니다. 내보내기 파일에 로그인 비밀 토큰을 넣지 않습니다.

3. 외부 서비스와 처리 위치

  • Supabase: 계정 인증, 게임 기록과 순위 저장을 제공합니다. 게임 데이터베이스는 대한민국 서울 리전을 사용합니다. 인증·운영에 필요한 일부 서비스와 하위 처리자는 국외에서 정보를 처리할 수 있습니다. Supabase 개인정보 안내.
  • Apple·Google: 사용자가 선택한 로그인 제공자입니다. 연결 과정에서 각 서비스의 안내와 정책이 적용됩니다. Apple 개인정보 안내, Google 개인정보 안내.
  • Google AdMob: 광고 및 동의 관리를 제공합니다. Google과 광고 파트너의 서버는 여러 국가에 위치할 수 있습니다. 파트너 앱의 정보 사용, 광고 도구의 정보 처리 항목.
  • GitHub Pages: 이 고객지원 사이트를 호스팅합니다. 보안을 위한 방문 IP 기록이 수집될 수 있습니다. 이 사이트에는 별도의 광고·방문 분석 코드를 넣지 않았습니다. GitHub 개인정보 안내.

4. 보유 기간과 삭제

게임 계정과 연결된 게임 기록은 서비스를 이용하는 동안 보관하며, 계정 삭제가 완료되면 운영 중인 게임 데이터베이스에서 연결된 기록을 삭제합니다. 기기의 데이터는 앱의 삭제·초기화 동작으로 제거합니다. 문의 내용은 문의 처리가 끝나면 삭제하며, 사용자가 추가 지원을 요청한 경우 그 처리에 필요한 동안 보관합니다.

외부 서비스의 보안 로그·백업은 각 서비스의 보유 정책에 따라 남을 수 있습니다. 법령상 보관 의무가 적용되는 정보는 해당 목적과 기간에 한해 따로 보관합니다. 네트워크 오류로 삭제 결과를 확인하지 못한 경우 앱에서 완료됐다고 표시하지 않으며, 재확인 또는 지원 문의를 안내합니다.

5. 사용자의 선택과 권리

계정 연결은 선택 사항입니다. 게임 설정에서 제공되는 개인정보 선택 항목과 기기의 광고·추적 설정을 사용할 수 있습니다. 계정 정보 열람, 정정, 삭제 또는 처리에 관한 문의는 아래 이메일로 요청할 수 있습니다. 요청자를 확인하는 데 필요한 최소 정보만 요청하며 비밀번호나 인증 코드는 요구하지 않습니다.
