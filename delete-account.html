계정과 기록 삭제

윙도쿠의 계정과 연결된 게임 기록을 삭제하려면 아래 방법을 이용하세요.

앱에서 삭제

  1. 앱의 설정 → 기록과 계정을 엽니다.
  2. 삭제하려는 계정이 맞는지 확인합니다.
  3. 계정과 기록 삭제 안내를 읽고 삭제를 진행합니다.
  4. 서버 삭제 완료 안내를 확인합니다. 인터넷 연결이 끊기면 다시 연결한 뒤 삭제 결과를 재확인하세요.

계정, 연결된 진행 기록, 보상과 순위 기록을 삭제합니다. 삭제 후에는 같은 계정으로 로그인해도 이전 기록을 복원할 수 없습니다. 보관용으로 내보낸 파일은 온라인 계정 복원 수단이 아닙니다.

앱을 이용할 수 없는 경우

아래 주소로 삭제 요청을 보내주세요. 앱에 연결한 로그인 방식과 계정 이메일, 확인 가능한 닉네임을 알려주시면 본인 확인 후 처리합니다. 게스트라면 앱에서 확인 가능한 사용자 식별자가 도움이 됩니다. 확인에 필요한 정보를 다시 안내할 수 있습니다.
